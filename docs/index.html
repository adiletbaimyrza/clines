Measure your codebase. Zero config.

A fast CLI that counts code, comments and blanks per language, finds duplicate code, ranks your complexity hotspots, and estimates what the repo costs an AI agent to read.

Why clines

Small, accurate, and built for code-health analysis.

🚀

Zero config

Run it and go — no config file is ever written to your repo. Sensible defaults, out of the box.

🙈

.gitignore aware

Respects your .gitignore and skips lockfiles, source maps and build junk by default.

📊

Per-language table

Code, comments and blanks per language — verified against cloc to the line.

🌌

Cosmic size scale

From Meteoroid to Universe — an honest, calibrated sense of scale.

📝

README integration

Keep a live metrics section in your README with --readme.

👯

Duplicate detection

clines dup finds copy-pasted blocks, reports a duplication percentage, and writes a browsable --html report with code snippets.

🔥

Complexity hotspots

clines cx ranks every file by its decision-point count, so you know exactly where the logic is dense — terminal or --html.

🤖

AI context cost

clines ctx estimates what your repo costs an AI agent to read, how much of a context window it fills, and fails CI above a --max token budget.

✅

100% tested

A layered, fully-covered TypeScript core, published tokenlessly with provenance.

Usage

count is read-only by default — it never touches your files unless you ask. 

# count the current directory, print the table
$ npx clines count

# count a specific directory
$ npx clines count src

# also write the report into README.md
$ npx clines count --readme

# find duplicated code blocks
$ npx clines dup

# rank files by complexity, into a browsable report
$ npx clines cx --html cx-report.html

# what does this repo cost an AI agent to read?
$ npx clines ctx --window 1m

# fail CI once the repo no longer fits a 200k window
$ npx clines ctx --max 200k

# the bare command prints a banner + version
$ npx clines
README markers. Place the clines · code metrics and clines · end marker comments anywhere in your README and the section between them stays up to date. No markers? The report is appended to the bottom.

Configuration

Optional. Add a clines.json to tweak the defaults with a simple add / remove model — for both directories and files. 

{
  "ignore": {
    "dirs": ["fixtures", "vendor"],
    "files": ["CHANGELOG.md"],
    "extensions": [".snap"],
    "globs": ["**/*.min.js"]
  },
  "unignore": {
    "dirs": ["public"],
    "files": ["package.json"]
  },
  "respectGitignore": true
}
